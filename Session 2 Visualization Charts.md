#### **Session 2: Visualization Charts and Apply Filter**



##### **Objective :**



**The objective of this session is to learn how to create visualizations, apply filters, add a new report page, and insert a text box in Power BI.**



##### **Theory :**



**In this session, I created different visualizations in Power BI using the given dataset. I used a Bar Chart to compare sales by category and a Pie Chart to show sales by region.**

**After that, I explored the Home and Insert tabs in the Ribbon. I added a new report page and inserted a text box with my name.**



**These features help make reports clear, interactive, and easy to understand.**



##### **Conclusion :**



**This session helped me understand how to create charts, apply filters, and use basic Power BI tools. These features make reports more attractive and useful for data analysis.**
